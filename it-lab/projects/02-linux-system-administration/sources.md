# Sources

- **Linux manual pages (`man`).** The built-in manual for `chmod`, `chown`, `setfacl`, `ps`, `top`, `crontab`, `ssh`, and the rest.
- **Negus, Christopher. *Linux Bible*. 10th ed., Wiley, 2020.** Permissions and ACLs, process management, and the system-administration chapters.
- **Barrett, Daniel J. *Linux Pocket Guide*. 3rd ed., O'Reilly Media, 2016.** Quick reference for the permission, process, and networking commands.
- **Debian `apt` documentation.** `https://www.debian.org/doc/manuals/debian-reference/ch02.en.html` Package install, update, and removal.
- **`crontab(5)` format reference.** `https://man7.org/linux/man-pages/man5/crontab.5.html` The five-field schedule syntax.
- **OpenSSH manual.** `https://man.openbsd.org/ssh` Client options including `-p` and `-v`.
