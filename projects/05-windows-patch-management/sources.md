# Sources

- **PSWindowsUpdate module.** `https://www.powershellgallery.com/packages/PSWindowsUpdate` The community module that wraps the Windows Update engine for PowerShell.
- **Microsoft, Get-HotFix.** `https://learn.microsoft.com/powershell/module/microsoft.powershell.management/get-hotfix` Reading back installed updates to verify a patch run.
- **Microsoft, Out-File.** `https://learn.microsoft.com/powershell/module/microsoft.powershell.utility/out-file` Writing command output to a text file.
- **Microsoft, Tee-Object.** `https://learn.microsoft.com/powershell/module/microsoft.powershell.utility/tee-object` Writing output to a file while still showing it on screen.
- **Microsoft, Set-ExecutionPolicy.** `https://learn.microsoft.com/powershell/module/microsoft.powershell.security/set-executionpolicy` Scoping the execution-policy change to the current process.
- **Susan Bradley, "How to use PowerShell to scan for Windows security updates."** CSO Online, 15 Nov 2018. `https://www.csoonline.com/article/566553/how-to-use-powershell-to-scan-for-windows-10-security-updates.html`
- **Harm Veenstra, "Using the PowerShell PSWindowsUpdate module."** PowerShellIsFun, 19 Jan 2024. `https://powershellisfun.com/2023/01/19/using-the-powershell-pswindowsupdate-module/`
