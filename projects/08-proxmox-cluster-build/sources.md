# Sources

- **Proxmox VE Administration Guide, cluster manager.** `https://pve.proxmox.com/pve-docs/pvecm.1.html`
  `pvecm add`, cluster membership, votes, and quorum checks.
- **Proxmox VE Administration Guide, firewall.** `https://pve.proxmox.com/pve-docs/chapter-pve-firewall.html`
  Datacenter firewall groups, rule order, compile checks, and service restart workflow.
- **Corosync documentation, votequorum.** `https://manpages.debian.org/corosync-votequorum`
  The odd-vote quorum model used by the three-node cluster.
- **Private build notes.**
  The original cluster setup, node-preparation, and firewall notes are kept outside the repo.
