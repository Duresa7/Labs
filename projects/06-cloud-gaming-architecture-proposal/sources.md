# Sources

- **AWS Pricing Calculator.** `https://calculator.aws/`
  The basis for the monthly cost estimate (EC2 m5.large, EBS, data transfer, snapshots).
- **AWS, EC2 instance types (the M5 general-purpose family).** `https://aws.amazon.com/ec2/instance-types/m5/`
  Why an m5.large fits a CPU- and RAM-intensive game server better than a burstable micro instance.
- **AWS, EC2 On-Demand pricing.** `https://aws.amazon.com/ec2/pricing/on-demand/`
  The pricing model behind "stop the instance when idle" as the main cost lever.
- **Valve, SteamCMD documentation.** `https://developer.valvesoftware.com/wiki/SteamCMD`
  The tool used to install and update the dedicated server (Arma 3 Dedicated Server, Steam app id 233780).
- **Bohemia Interactive, Arma 3 Dedicated Server setup.** `https://community.bistudio.com/wiki/Arma_3:_Dedicated_Server`
  Server requirements and configuration that informed the instance sizing and port choice.
- **Deloitte, on cloud gaming economics.** `https://www2.deloitte.com/us/en/insights/industry/technology/cloud-gaming-video-game-industry.html`
  Background research for the proposal's framing.
