# Sources

- **Microsoft, Windows kernel-mode architecture.** `https://learn.microsoft.com/windows-hardware/drivers/kernel/` The NT hybrid kernel and kernel-mode drivers.
- **The Linux Kernel documentation.** `https://docs.kernel.org/` The monolithic kernel, loadable modules, and subsystems.
- **Apple, Kernel Architecture Overview.** `https://developer.apple.com/library/archive/documentation/Darwin/Conceptual/KernelProgramming/Architecture/Architecture.html` The XNU (Mach + BSD) kernel underpinning macOS.
- **Microsoft, Windows security documentation.** `https://learn.microsoft.com/windows/security/` UAC, Microsoft Defender, and BitLocker.
- **SELinux and AppArmor project documentation.** Mandatory access control on Linux.
- **Apple Platform Security guide.** `https://support.apple.com/guide/security/` Gatekeeper, System Integrity Protection, and FileVault.
