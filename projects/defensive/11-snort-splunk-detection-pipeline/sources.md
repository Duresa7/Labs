# Sources

- **Snort.** `https://www.snort.org/` The open-source IDS, its rule format, and running it in promiscuous mode.
- **Splunk, "About forwarding and receiving data."** `https://docs.splunk.com/Documentation/Splunk/latest/Forwarding/Aboutforwardingandreceivingdata` How the Universal Forwarder ships data to an indexer.
- **Splunk, Universal Forwarder.** `https://docs.splunk.com/Documentation/Forwarder/latest/Forwarder/Abouttheuniversalforwarder` The lightweight agent and its default receiving port (TCP 9997).
- **Splunk, "Monitor files and directories."** `https://docs.splunk.com/Documentation/Splunk/latest/Data/Monitorfilesanddirectories` Tailing a log file such as the Snort alert file as an input.
- **MITRE ATT&CK.** `https://attack.mitre.org/` The technique taxonomy used to group detections (Reconnaissance, Credential Access).
