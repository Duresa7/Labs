# Sources

- **Linux manual pages (`man`).** The built-in manual for every command used here, and the first place I checked for flags and behavior.
- **Barrett, Daniel J. *Linux Pocket Guide*. 3rd ed., O'Reilly Media, 2016.** A quick reference for the core file, navigation, and search commands.
- **Negus, Christopher. *Linux Bible*. 10th ed., Wiley, 2020.** Background on the shell, the filesystem layout, and how the commands fit together.
- **GNU Coreutils manual.** `https://www.gnu.org/software/coreutils/manual/` Reference for `ls`, `cp`, `mv`, `rm`, `cat`, `stat`, `ln`, and the other core utilities.
