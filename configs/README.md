# Configs

Sanitized reference artifacts that back the chapters. Addresses, keys, and names are placeholders; the structure is what I actually run.

| File | What it is |
|---|---|
| `switch-baseline.cfg` | The IOS-style baseline I bring a switch up with: VLANs, a pruned trunk, SSH-only management, no Telnet. Backs [chapter 05](../docs/05-switching.md) and [chapter 08](../docs/08-fundamentals.md). |
| `wireguard-server.example.conf` | The shape of the Management Access WireGuard server from [chapter 04](../docs/04-remote-access.md), with keys redacted. |

These are illustrative baselines, not drop-in configs. Read them before adapting anything.
