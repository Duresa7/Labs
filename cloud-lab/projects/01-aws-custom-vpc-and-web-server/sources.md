  Subnets, route tables, internet gateways, and the public/private distinction.

  The stateful, instance-level firewall and inbound-rule behavior.
- **AWS CLI command reference (`ec2`).** `https://docs.aws.amazon.com/cli/latest/reference/ec2/`
  The commands in [commands.md](commands.md).
- **AWS, "Run instances" / EC2 user guide.** `https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/`
  AMI selection, instance types, and user-data boot scripts.
